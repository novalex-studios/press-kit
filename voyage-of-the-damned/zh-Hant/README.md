# Press Kit

回合制敘事生存遠航。1904至1905年，率領俄國第二太平洋分艦隊，歷時224天駛向對馬：調配煤炭、維持秩序、熬過疫病與譁變，帶著一支名副其實的分艦隊抵達。這一次，走出比歷史更好的結局。

**航程盡頭的那場海戰，史書早已寫下敗局。而此前的七個月，由你執掌。**

日復一日，你從波羅的海駛向朝鮮海峽：十三個航段，224天。每個航段啟程前，你查看海圖、煤炭存量與各艦軍心，擇定一道常令，然後出海；直到下一個航段，分艦隊都只奉這一道常令航行。接著，天氣、中立港口與你自己的官兵會作出回應，下一個航段，便從所剩的存量開始。

## 舉一個抉擇為例

把煤堆上甲板，即使運煤船錯過會合點，分艦隊也能抵達達卡。但甲板載煤會拖累航速與穩性，煤在船上多留一天，水兵便多承受一天的士氣消磨與疲勞。輕裝出航，各艦保持靈活，但從此成敗全繫於運煤船是否如期出現。

## 與眾不同之處

- **遠航本身就是這款遊戲。**煤炭、士氣、砲術操練、船底污損與分艦隊凝聚力，彼此牽動，一項短缺，往往會在224天裡拖累其餘各項。
- **海戰是最後的大考。**本作沒有戰術戰鬥。對馬是一場精心編寫的大場面，只需做出寥寥幾項司令決斷，勝負由你帶到戰場的分艦隊決定。輸贏早在途中的裝煤港與錨地便已注定。聖彼得堡可能在半途解除你的指揮權；輸掉海戰，分艦隊便葬身海峽；你若從這場敗仗中生還，等著你的不是俘虜生涯，便是軍法審判。
- **真正的抉擇。**在丹吉爾，是讓噸位較小、吃水較淺的艦船走蘇伊士運河，還是讓整個分艦隊一同繞行好望角？在馬達加斯加，是等待涅博加托夫的增援，還是不等他們就出航？到了最後，選擇你的海峽：朝鮮海峽、宗谷海峽或津輕海峽。
- **你的常令塑造這支分艦隊。**「全速兼程」或「保持編隊」，「勤練砲術」或「體恤官兵」，「隱跡航行」或「穩健航行」：你在每個航段擇定的那一道常令，決定最終抵達的是怎樣一支分艦隊。
- **司令的權宜之計。**萬不得已時的寥寥幾招，每一招在一趟遠航中只能用一次，用過便不再有：一份伏特加配給、一次懲一儆百、一則瞞著水兵的消息。每一招都能換來喘息，卻也各有代價。
- **每趟遠航都有一組專屬的每日令號。**每日令號相同，天氣、故障、事件與運氣也就相同。把你的每日令號告訴朋友，對方踏上的便是同一趟遠航，不同的只有各自的抉擇。

## 由親歷者講述

這趟遠航由分艦隊總工程師葉夫根尼·波利托夫斯基的家書講述。他幾乎每天寫信給妻子，最後隨旗艦蘇沃洛夫公爵號葬身對馬。其餘則出自倖存者弗拉基米爾·謝苗諾夫的記述。波利托夫斯基的家書止於海上，就在海戰前不久；謝苗諾夫的記述則將故事帶進海峽。

## 史實，以及本作與史實的分歧

航線、艦船、日期與災難皆為史實：多格灘之夜、馬達加斯加外海的漫長等待、涅博加托夫的老舊艦船在中南半島外海趕上會合。每一則編入遊戲的事件都標註為史實、推測或反事實，而每一則史實事件，都註明出處。

## 真實的艦船，真實的史料

艦型識別剪影描摹自當時的圖版與照片，大多出自《詹氏戰艦年鑑》（Jane's Fighting Ships）；圖鑑圖版則取自同期的書籍與照片，其中包括詹氏的出版物、《Brassey's Naval Annual》和阿波斯托利的明信片。全部屬於公有領域，並在遊戲中註明出處。
