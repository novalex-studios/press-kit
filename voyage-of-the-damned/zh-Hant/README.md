# Press Kit

1904至1905年，一場回合制敘事生存遠航。把煤堆上甲板，就算運煤船沒來，你照樣到得了達卡；但艦船會因此變慢，官兵也得跟著吃苦。從波羅的海到對馬，224天裡盡是這樣的取捨。

**航程盡頭的那場海戰，史書早已寫下敗局。而此前的七個月，由你執掌。**

1904年，俄國派出波羅的海的軍艦，遠渡半個地球去與日本交戰。你將統率這支分艦隊，從波羅的海駛向朝鮮海峽，歷時224天、十三個航段。每個航段啟程前，你查看海圖、煤炭存量與各艦軍心，然後擇定一道常令，起錨出海。天氣、中立港口與麾下官兵各有反應；下一個航段，就從剩下的家底起步。

## 勝負決於途中

本作沒有戰術戰鬥。對馬海戰是一場精心編排的大場面，你將做出寥寥幾項司令決斷，真正左右戰局的，是你帶到戰場上的那支分艦隊。早在抵達海峽之前，勝敗就已在一處處裝煤港與錨地分出。

## 可能的結局

你還沒抵達海峽，聖彼得堡就可能解除你的指揮權。輸掉海戰，分艦隊便葬身海峽；你若在敗仗中生還，等著你的不是俘虜生涯，便是軍法審判。最終的裁決，看的是你帶著闖過去的主力艦有幾艘。

## 舉一個抉擇為例

把煤堆上甲板，即使運煤船錯過會合點，分艦隊也能抵達達卡。但甲板載煤會拖累航速與穩性，煤在船上多留一天，水兵便多承受一天的士氣消磨與疲勞。輕裝出航，各艦保持靈活，但從此成敗全繫於運煤船是否如期出現。

## 每個航段，一道常令

「全速兼程」還是「保持編隊」？「勤練砲術」還是「體恤官兵」？「隱跡航行」還是「穩健航行」？你選定的常令，一直有效到下一個航段。煤炭、士氣、砲術操練、船底附著與凝聚力彼此牽動，一項惡化，往往連帶拖垮其餘各項。到了最難熬的日子，你還有幾招權宜之計，例如發一份伏特加配給，或把某則消息瞞著水兵。每一招只能用一次，用過之後，這趟遠航裡便再也沒有了。

每趟遠航都有自己的每日令號。把你的令號告訴朋友，對方遇上的天氣、故障與事件，便與你的一模一樣。

## 改變航路的抉擇

在丹吉爾，你可以讓噸位較小、吃水較淺的艦船取道蘇伊士，也可以讓整個分艦隊一同繞行好望角。在馬達加斯加，你可以等候涅博加托夫的增援，也可以不等他們逕自出航。到了最後，你要選擇走哪一道海峽：朝鮮海峽、宗谷海峽，還是津輕海峽。

## 總工程師的家書

分艦隊總工程師葉夫根尼·波利托夫斯基幾乎每天都寫信給妻子，這趟遠航便由他的家書講述。書信止於海上，就在海戰前不久；他本人則在對馬與旗艦蘇沃洛夫公爵號一同沉沒。

## 史實，以及本作與史實的分歧

航線、艦船、日期與災難皆為史實：多格灘之夜、馬達加斯加外海的漫長等待、涅博加托夫的老舊艦船在中南半島外海趕上會合。每一則編入遊戲的事件都標註為史實、推測或反事實，而每一則史實事件都附有史料出處。艦船圖版取自當時的書籍與照片，全部屬於公有領域，並在遊戲中註明來源。
