# Press Kit

一款回合制叙事生存游戏，讲述1904至1905年的一场远航。在甲板上堆满煤，即使运煤船没来，你也能抵达达喀尔；可各舰航速会因此下降，水兵也要跟着吃苦。从波罗的海到对马，224天里，尽是这样的抉择。

**远航尽头的那场海战，史书早已写下败局；而此前的七个月，由你执掌。**

1904年，俄国把波罗的海的军舰派往半个地球之外，去和日本交战。你将统率这支分舰队，从波罗的海直抵对马海峡，历时224天，走完十三个航段。每个航段出发前，你查看海图、煤炭存量和各舰士气，然后选定一道常令，起航出海。天气、中立港口和你自己的舰员都会作出回应，下一个航段，便从余下的家底开始。

## 胜负，早在途中便已注定

本作没有战术战斗。对马海战是一场精心编排的重头戏，司令只需做出寥寥几项决断；胜负取决于你带去的是一支怎样的分舰队。早在驶入海峡之前，这一仗的输赢就已在一个个装煤港和锚地里见了分晓。

## 远航可能的结局

你可能还没到海峡，就被圣彼得堡解除了指挥权。输掉海战，分舰队便葬身海峡；你若从败仗中生还，等待你的不是被俘，便是军事法庭。最后的评判，要看你有多少主力舰挺过了这一路。

## 抉择一例

在甲板上堆满煤，即使运煤船错过会合点，分舰队也能抵达达喀尔。但甲板载煤会拖慢航速、削弱稳性，煤一日不卸，水兵便一日受累，士气也日渐低落。轻装航行，舰船操纵灵活，可成败就全押在运煤船能否如约而至上了。

## 每个航段，一道常令

全速前进，还是保持队形？炮术操演，还是体恤船员？潜行航渡，还是稳步航行？你选定的常令一直生效到下一航段。煤炭、士气、炮术操练、船底附着与凝聚力彼此牵制，一项下滑，往往会拖累其余各项。到了最难熬的日子，你手里还有几样万不得已的手段，比如一份伏特加配给，或是一条瞒着普通水兵的消息。每样手段只能用一次，用过之后，本次远航便再也没有了。

每次远航都有一个军令编号。把你的编号告诉朋友，对方遇上的天气、故障与事件便和你分毫不差。

## 改变航路的抉择

在丹吉尔，你可以让较小、吃水较浅的舰船取道苏伊士运河，也可以让整个分舰队一同绕行好望角。在马达加斯加，你可以等待涅博加托夫的增援，也可以不等他们径自起航。最后，你要选定海峡：朝鲜海峡、宗谷海峡或津轻海峡。

## 总工程师的家书

分舰队总工程师叶夫根尼·波利托夫斯基几乎每天都给妻子写信，远航便由这些家书讲述。家书止于海上，就在海战前不久；他本人随旗舰苏沃洛夫公爵号葬身对马。

## 史实，与本作的改动

航线、舰船、日期和灾难都是史实：多格滩之夜、马达加斯加外海的漫长等待、涅博加托夫的老旧舰船在印度支那外海赶来会合。游戏中的每个事件都标注为史实、推测或反事实；凡是史实事件，皆注明出处。舰船图版取自当时的书籍与照片，全部属于公有领域，并在游戏中注明来源。
