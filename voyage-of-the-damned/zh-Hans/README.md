# Press Kit

回合制叙事生存策略游戏。1904至1905年，率领俄国第二太平洋分舰队，历时224天驶向对马：调配煤炭、维持秩序、熬过疾病与哗变，带着一支仍堪一战的分舰队抵达。这一次，力求胜过历史。

**远航尽头的那场海战，史书早已写下败局；而此前的七个月，由你执掌。**

日复一日，你从波罗的海驶向对马海峡：十三个航段，224天。每个航段之前，你查看海图、煤炭存量和舰员士气，选定一道常令，然后起航；直到下一航段，分舰队都依此令而行。接着，天气、中立港口和你自己的舰员会作出回应，下一个航段，便从余下的家底开始。

## 抉择一例

在甲板上堆满煤，即使运煤船错过会合点，分舰队也能抵达达喀尔。但甲板载煤会损失航速和稳性，煤一日不卸，水兵便一日受累，士气日渐低落。轻装航行，舰船灵活，但成败全系于运煤船能否如约而至。

## 与众不同之处

- **远航即是游戏本身。**煤炭、士气、炮术、船底附着与凝聚力，彼此牵制，一项短缺，往往会在224天里拖累其余各项。
- **海战是最后的大考。**本作不设战术战斗玩法。对马是一段精心编写的关键场景，只需作出寥寥几项司令决断，胜负取决于你带到战场的分舰队。胜败早在途中的装煤港和锚地就已注定。圣彼得堡可能在半途解除你的指挥权；输掉海战，分舰队葬身海峡；你若从这场败仗中生还，等待你的不是被俘，便是军事法庭。
- **真正的抉择。**在丹吉尔，是让较小、吃水较浅的舰船走苏伊士运河，还是让整个分舰队绕行好望角？在马达加斯加，是等待涅博加托夫的增援，还是不等他们就起航？最后，选择你的海峡：朝鲜海峡、宗谷海峡或津轻海峡。
- **你的命令决定分舰队的模样。**全速前进还是保持队形，炮术操演还是体恤船员，潜行航渡还是稳步航行：每个航段你选定哪一道常令，决定了最终抵达的是怎样一支分舰队。
- **将旗之下的权宜之计。**这样的权宜之计，你手中只有寥寥几样：一份伏特加配给、一次惩一儆百、一条瞒着普通水兵的消息。都是万不得已才动用的，每样只能用一次，用过，这次远航便不再有。样样都能解一时之急，却也各有代价。
- **每次远航都有一道当日军令。**当日军令编号相同，天气、故障、事件与命运便分毫不差。把你的军令编号告诉朋友，朋友经历的便是同一次远航；不同的，只是各自的抉择。

## 亲历者的讲述

远航由分舰队总工程师叶夫根尼·波利托夫斯基的家书讲述。他几乎每天给妻子写信，最终随旗舰苏沃洛夫公爵号葬身对马。另一位讲述者是幸存下来的弗拉基米尔·谢苗诺夫。波利托夫斯基的家书止于海上，就在海战前不久；谢苗诺夫的记述则把故事带入海峡。

## 史实，与本作的改动

航线、舰船、日期和灾难都是史实：多格滩之夜、在马达加斯加外海的漫长等待、涅博加托夫的老旧舰船在印度支那外海赶来会合。每个事件都标注为史实、推测或反事实，每个史实事件都注明出处。

## 真实的舰船，真实的史料

舰型识别剪影描摹自当时的图版与照片，大多出自《简氏战舰年鉴》（Jane's Fighting Ships）；图鉴插图取自当时的书籍与照片，其中包括简氏的出版物、《Brassey's Naval Annual》和阿波斯托利的明信片。均属公有领域，并在游戏中注明出处。
