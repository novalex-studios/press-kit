# Press Kit

1904〜05年の航海を描く、ターン制ナラティブ・サバイバル。甲板に石炭を積み上げれば、給炭船が来なくてもダカールにはたどり着ける。だが艦の速力は落ち、乗組員はそのしわ寄せに苦しむ。バルト海から対馬海峡までの224日は、こうした決断の連続だ。

**最後の海戦は、歴史書の上ではすでに負け戦だ。だが、そこに至る七か月の舵を取るのは自分だ。**

1904年、ロシアは日本と戦うため、バルト海の艦艇を、世界を半周する航海に送り出した。その分艦隊を率いて、バルト海から対馬海峡まで、十三の航程、224日を進む。航程ごとに、まず海図と石炭の残量、乗組員の士気を読む。そして航海命令を一つ定め、出航する。その命令に、天候が、中立港が、そして麾下の乗組員が応える。次の航程は、手元に残ったものだけで始まる。

## 海戦の勝敗は道中で決まる

戦術戦闘はない。日本海海戦は作り込まれた山場で、提督が下す決断は数えるほどだ。勝敗を決めるのは、そこまで率いてきた分艦隊そのもの。勝ち負けは、海峡のずっと手前、給炭地や錨地で決まっていく。

## 航海の結末

海峡にたどり着く前に、サンクトペテルブルクから指揮を解かれることもある。海戦に敗れれば、分艦隊はその海で果てる。敗北を生き延びても、待っているのは捕虜生活か軍法会議だ。歴史の審判が数えるのは、海峡を突破させ、最後まで率いきった主力艦の数だ。

## たとえば、ある決断

甲板に石炭を積み上げれば、給炭船が合流地点に現れなくても、分艦隊はダカールまでたどり着ける。だが甲板積みは速力と復原性を損ない、石炭が甲板にある限り、そのつけは毎日、水兵の士気の低下と疲労となって積み重なる。身軽に航海すれば艦は扱いやすいままだが、そのかわり、すべては給炭船が現れるかどうかにかかる。

## 航程ごとに、航海命令を一つ

「全速前進」か「隊列維持」か。「砲術訓練」か「乗員の休養」か。「灯火管制航行」か「平常航海」か。選んだ命令は次の航程まで変わらない。石炭、士気、砲術、船底汚損、統制は互いに絡み合っていて、一つが崩れると、ほかもつられて崩れがちだ。本当に苦しい日には、ウォッカの配給や、水兵たちへの知らせの秘匿といった、最後の手段がいくつかある。どれも効くのは一度きりで、使えばその航海では二度と使えない。

どの航海にも番号が振られている。自分の航海の番号を友人に伝えれば、友人の航海にも同じ天候が巡り、同じ故障や同じ出来事が起こる。

## 航路を変える選択

タンジールでは、小型で喫水の浅い艦をスエズ経由で送るか、分艦隊をまとめたまま喜望峰を回るか。マダガスカルでは、ネボガトフの増援を待つか、待たずに出航するか。そして最後に、抜ける海峡を選ぶ。対馬海峡か、津軽海峡か、宗谷海峡か。

## 機関長の書簡

分艦隊の機関長エヴゲーニー・ポリトフスキーは、ほぼ毎日、妻に手紙を書き送った。航海を語るのは、その書簡だ。手紙は海戦の少し前、洋上で途絶える。彼は日本海海戦で、旗艦クニャージ・スヴォーロフとともに帰らぬ人となった。

## 史実と、史実から離れるところ

航路、艦艇、日付、そして災厄は史実どおりだ。ドッガーバンクの夜、マダガスカル沖での長い待機、インドシナ沖で追いついたネボガトフの旧式艦。作中の出来事にはすべて「史実」「蓋然性」「仮想」のいずれかのタグが付き、史実の出来事にはすべて出典が示されている。艦艇の図版は当時の書籍や写真から採ったもので、いずれもパブリックドメインであり、ゲーム内にクレジットを記載している。
