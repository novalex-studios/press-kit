# Press Kit

1904〜05年、ロシア第二太平洋艦隊を率いて対馬海峡まで224日の航海に挑む、ターン制ナラティブ・サバイバルゲーム。石炭を配分し、軍紀を保ち、疫病と反乱を乗り越え、戦える分艦隊のまま海峡にたどり着け。史実を超える航海を。

**歴史書の上では、航海の果ての海戦はすでに敗北に終わっている。だが、そこに至る七か月の航海は、まだ誰にも書かれていない。**

一日ずつ、バルト海から対馬海峡までの航海を進めていく。十三の航程、224日。航程ごとに海図と石炭の残量、乗組員の士気を読み、その航程のあいだ分艦隊が従う航海命令を一つだけ定めて出航する。あとは天候と中立港、そして麾下の乗組員しだいだ。次の航程は、手元に残ったものでやりくりするしかない。

## たとえば、ある決断

甲板に石炭を積み上げれば、給炭船が合流地点に現れなくても分艦隊はダカールにたどり着ける。だが甲板積みは速力と復原性を損ない、石炭が甲板にある限り、水兵の士気は日々すり減り、疲労が積み重なっていく。身軽に航海すれば艦は扱いやすいままだが、すべては給炭船が現れるかどうかにかかる。

## 本作の特徴

- **航海こそがゲーム。**石炭、士気、砲術訓練、船底汚損、分艦隊の統制。これらは互いに影響し合い、一つが崩れれば、224日を通じて残りもつられて崩れがちだ。
- **海戦は答え合わせ。**戦術戦闘はない。日本海海戦は作り込まれた山場で、提督の決断はわずか数回。海戦の行方を決めるのは、そこまで率いてきた分艦隊の姿だ。その姿は、ずっと手前の給炭地や錨地ですでに決まっている。航海の途中でサンクトペテルブルクから解任されることもある。海戦に敗れれば分艦隊は海峡に沈み、提督がその敗北を生き延びても、待つのは捕虜生活か軍法会議だ。
- **史実の分岐点。**タンジールでは、小型で喫水の浅い艦をスエズ経由で送るか、分艦隊全体で喜望峰を回るか。マダガスカルでは、ネボガトフの増援を待つか、待たずに出航するか。最後に、抜ける海峡を選ぶ。対馬海峡か、津軽海峡か、宗谷海峡か。
- **命令が分艦隊を形づくる。**「全速前進」か「隊列維持」か、「砲術訓練」か「乗員の休養」か、「灯火管制航行」か「平常航海」か。航程ごとに選ぶ航海命令が、どんな分艦隊が到着するかを決める。
- **提督の方策。**数えるほどしかない最後の手段だ。いずれも一度使えば、その航海ではそれきりになる。ウォッカの配給、見せしめ、水兵たちに伏せた知らせ。どれも急場はしのげるが、ただでは済まない。
- **どの航海にも日々命令がある。**日々命令には番号が振られており、その番号が同じなら、天候も故障も出来事も、運命の巡り合わせまで同じになる。自分の日々命令番号を友人に伝えれば、友人も同じ航海に出られる。違ってくるのは、道中で下す決断だけだ。

## そこにいた者たちが語る

航海を語るのは、分艦隊の機関長エヴゲーニー・ポリトフスキー。彼はほぼ毎日妻に手紙を書き送り、日本海海戦で旗艦クニャージ・スヴォーロフとともに帰らぬ人となった。もう一人の語り手は、生還したウラジーミル・セミョーノフだ。ポリトフスキーの書簡は海戦の少し前、洋上で途絶える。その先、海峡での物語はセミョーノフの記録が引き継ぐ。

## 史実と、史実から離れるところ

航路、艦艇、日付、そして災厄は史実どおりだ。ドッガーバンクの夜、マダガスカル沖での長い待機、インドシナ沖で追いついたネボガトフの旧式艦。作中の出来事にはすべて「史実」「蓋然性」「仮想」のいずれかのタグが付き、史実の出来事にはすべて出典が示されている。

## 本物の艦、本物の史料

識別用のシルエットは、同時代の図版や写真、主に『ジェーン海軍年鑑』（Jane's Fighting Ships）の掲載図からトレースした。図鑑の図版には当時の書籍や写真を用いており、出典は『ジェーン海軍年鑑』、『Brassey's Naval Annual』、アポストリの絵葉書などだ。いずれもパブリックドメインで、ゲーム内にクレジットを記載している。
