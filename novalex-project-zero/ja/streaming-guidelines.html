要点

本作のプレイ動画は、録画・配信・収益化のいずれも自由に行えます。事前の申請は不要で、別途のライセンス契約も 必要ありません。ネタバレの解禁日も、公開してよい範囲の上限も、どこを見せてよいかという制限もありません。この許諾は 体験版、製品版、そして今後リリースするすべての追加コンテンツ——アップデート、DLC、続編——に自動的に及びます。 新しいものが出るたびに本ページを確認し直す必要はありません。

許可していること

  • 録画と配信：生放送でも編集済み動画でも、形式や尺の制限なく行えます。
  • その動画の収益化：プラットフォームの広告、チャンネルメンバーシップ、サブスクリプション、スーパーチャット および同等の機能、スポンサー契約や案件動画のいずれも許可しています。
  • 有料動画・メンバー限定動画の公開：ペイウォールの内側、チャンネルメンバーシップの特典、Patreon や Fanbox の プラン、その他あらゆる購読者限定の公開形態を含みます。日本のガイドラインでは有料動画を別項目として扱い、既定で 「不可」とすることが多くありますが、本作では可です。制限はありません。
  • サムネイル素材の利用：プレスキットのキーアート、ロゴ、スクリーンショットは、本作を扱う動画のサムネイル、 チャンネルアート、概要欄で利用できます。

音声と Content ID

ひとつだけご注意いただきたい点があります。申し立ての通知で知るより、当方からお伝えしておきたい内容です。 効果音は CC0 で、申し立てのリスクはありません。一方、楽曲は Pixabay Content License に基づいて当方がライセンスを 受けたもので、各曲が YouTube Content ID に登録されています。そのため、本作の楽曲が入った動画には自動の 申し立てが付くことがあります。申し立ては違反警告（ストライク）ではありませんが、動画に広告が表示されたり、その 収益が別のところへ回ったりすることがあります。収益化されるのであれば、音楽の音量スライダーを 0 にして、ご自身の BGM を重ねてください。効果音のスライダーは別になっているので、ゲームらしい音はそのまま残ります。

OBS の設定や音声ソースの落とし穴を含む詳細は、本ページ下部からリンクしている収録ノートにまとめています。
