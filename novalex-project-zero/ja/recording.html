収録の手引き — 配信者・動画投稿者・メディアの方へ

はじめに要点だけ。本作には収録上の制限が一切ありません。 DRM も、保護コンテンツのフラグも、録画を黒く 塗りつぶすオーバーレイもありません。録画も配信も収益化も自由に行えます。

そのうえで、事前に知っておくと役立つことが 2 つあります。音声の取り方と、収益化する場合の Content ID に関する 注意点です。2026-08-02 に Windows 版 OBS Studio で、ウィンドウモードとフルスクリーンの両方で確認しています。

ウィンドウキャプチャ・画面キャプチャ — 設定は不要です

ウィンドウキャプチャも画面キャプチャも、OBS の初期設定のまま動作し、プロパティを変更する必要は ありません。画面キャプチャでも黒塗りや「保護されたコンテンツ」の表示は出ません。本作は DRM や保護ウィンドウの フラグを設定しておらず、そもそも塗りつぶす対象がないからです。

音声は「アプリケーション音声キャプチャ」ではなく「デスクトップ音声」で

音楽と効果音は WebView の子プロセスから出力されており、このプロセスは自前のトップレベルウィンドウを持ちません。 そのため OBS のアプリケーション音声キャプチャはこれを捕捉できず、ソースのウィンドウ一覧に本作は現れません。 メインの実行ファイルを選んでも、メーターは振れないままです。

代わりにデスクトップ音声のソースをお使いください。音声は通常の共有出力デバイスに、ずれなく、通常の音量で 届きます。Windows では、本作をアプリケーション単位で音声分離することはできません。

音楽と YouTube Content ID — 収益化する前にお読みください

申し立ての通知で知るより、先にお伝えしておきます。

  • 効果音は Creative Commons 0（パブリックドメイン）です。問題になることはありません。
  • 音楽——ゲーム内のすべての楽曲と、トレーラーの楽曲——は Pixabay Content License に基づいて当方が ライセンスを受けています。このライセンスは商用利用を認めていますが、各曲が YouTube Content ID に登録されて います。

実際に何が起きるかというと、本作の楽曲が入った動画には Content ID の自動の申し立てが付くことがあります。申し立ては 著作権侵害の警告（ストライク）ではありません。チャンネルにペナルティが付くことはありません。ただし、異議 申し立てが通るまでのあいだ、動画に広告が表示されたり、収益が申立者側へ回ったりすることがあります。当方が代わりに 解除することはできません。Pixabay のライセンス証明書が効力を持つのは、楽曲をダウンロードしたライセンシー本人、 つまり当方に対してだけで、あなたの手元では使えないためです。

収益化されるのであれば、音声設定で音楽の音量スライダーを 0 まで下げて、ご自身の BGM をお使いください。音楽と 効果音は独立した音量スライダーなので、効果音は鳴ったままです。効果音は CC0 で、申し立てのリスクはありません。 本作でこれ以外に申し立ての対象となるものはありません。

そもそもこれは、配信者の側で回避していただくような話ではなく、当方の素材選定の不備だと考えています。実際に支障が 出ているようなら、Content ID に登録されていない楽曲に差し替えます。もし申し立てを受けたら、ぜひ教えてください。 当方が動くきっかけになるのは、まさにその一報です。

フルスクリーンの映像が見切れる場合

これは OBS のシーン構成の問題で、ゲーム側の問題ではありません。モニターの解像度が OBS の基本（キャンバス） 解像度より大きいため、ソースがキャンバスからはみ出しています。プレビューでソースを選択し、Ctrl+F （画面に合わせる）を押してください。
